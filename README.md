# CollabDoc 📄

A cloud-based real-time document collaboration tool built with Java, JavaFX, and Firebase.

## Features
- 🔐 User Authentication (Login, Signup, Forgot Password)
- 📝 Rich Text Document Editor with formatting options
- ☁️ Cloud sync using Firebase Realtime Database
- 👥 Real-time Active Users panel
- 🔗 Document Sharing between users
- 💾 Auto-save every 5 seconds
- 📄 Multiple documents per user
- ⬇️ Download documents as TXT

## Tech Stack
- Frontend: JavaFX
- Backend/Cloud:Firebase (Authentication, Realtime Database)
- Language: Java
- IDE: IntelliJ IDEA
- Security: SHA-256 password hashing

## Security
Passwords are hashed using SHA-256 before storing in Firebase.
